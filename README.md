# Taller Arrieta — demo

Sitio de demostración del rubro **taller mecánico y aire acondicionado automotriz**, hecho con [Astro](https://astro.build).

Es un **negocio ficticio**. Sirve para mostrarle a un cliente potencial de ese
rubro cómo se vería su propia página, sin tener que imaginárselo.

## Correr en local

```bash
npm install
npm run dev
```

## Publicar

Se despliega como sitio estático. En Vercel: framework Astro, build `npm run build`,
salida `dist`. Dominio sugerido: `demo-taller-cr.vercel.app`.

## Notas

- El negocio, los nombres y los datos son inventados. No se usan el nombre, las
